Key Interaction Behaviors

  • HUD Pipeline Nodes: Each step in Eve's multi-agent chain (`intent`, `orchestrator`, `design_research`, `generate`, `autofix`, `security_review`) pulses with liquid light while active, turning solid emerald when verified. Clicking any node expands its thought trace and streaming event log.
  • Human-in-the-Loop Cards: When Eve triggers `ask_question` (like design approval or risky action permissions), an elegant glass card slides in with the exact options (`Approve and build`, `Revise design`, `Stop`) wired to `send({ inputResponses: ... })`.
  • Inspect Drawers: Clicking "File Explorer", "Terminal", or "Security Review" on the dock slides up a backdrop-blurred bottom or side drawer containing the Monaco Editor, git file diffs, or sandbox bash output without losing viewport context.
